## 요약

- 카드 한 장은 .md 파일 하나이고, frontmatter에 id, scope, access, 어휘 용어가 있으며 본문은 3줄 요약과 한계다.
- 후보는 일치한 용어 수, 본문 일치 수, 희귀 용어, id 순으로 정렬해 상위를 고르고, 검색한 카드 수도 함께 알려 준다.
- 어휘에 없는 검색어는 unknown_terms로 돌려줘서 조용히 빈 결과가 나오지 않는다. 판정은 세션 모델이 카드를 읽고 한다.
